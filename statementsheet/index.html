Four things you're probably wondering

How is this different from drawing a black box in Acrobat?

A black box and the highlight tool both leave the original text sitting in the file underneath. Acrobat's actual redaction feature is buried, and it's common to apply the mark and never apply the redaction — which looks identical on screen. This removes the text, the image data underneath it, and the document metadata, so there is nothing left to recover.

Does it work on scanned documents?

Yes, and it's worth knowing how, because scans behave differently. A scan is a picture — there is no text layer underneath the mark, so there is nothing to strip. What matters is that the image data under the mark is destroyed rather than painted over, and that's what this does. Where a scan has already been put through OCR and does carry a searchable text layer, that text is removed as well.
